# Procedencia, atribuciones y autoría de ¡Qué Pan!

## Logo institucional
El archivo logo-academico.png es una copia sin alteraciones de LOGO UMG.png, aportado por la usuaria para identificar su proyecto académico. Corresponde a la Universidad Mariano Gálvez de Guatemala. No es una creación del proyecto ni se reivindica su autoría. Su inclusión no constituye una declaración de patrocinio. Esta nota no acredita permiso o licencia de la institución; verificar sus reglas de uso de identidad visual.

## Imagen de pan e icono
La ilustración pan-pixel.png y el icono verde se generaron con asistencia de inteligencia artificial para este proyecto. Se utilizó una referencia visual aportada por la usuaria para orientar el estilo. No se presenta la fotografía de referencia como obra propia ni se incorpora esa captura al acceso. La generación asistida no permite certificar por sí sola que no existan semejanzas con otras imágenes. La usuaria debe revisar las normas académicas aplicables al uso de estas herramientas.

## Código y material recibido
El proyecto se desarrolló con asistencia de inteligencia artificial. La usuaria definió requisitos, aportó archivos y realizó verificaciones en navegador y Android. No es correcto describir todo el código como escrito exclusivamente sin asistencia por la estudiante. Las guías permiten estudiar y explicar el funcionamiento, no sustituyen esa declaración.
La versión Java y Oracle reutiliza la plantilla Jersey aportada para el curso. El ZIP de entrega integrada recibido contiene una implementación alternativa; se conserva aislada como referencia y sus flujos seleccionados se adaptaron a la solución existente. No se conoce ni se inventa el autor de los archivos aportados. Si pertenecen a otra persona, conservar su atribución y comprobar el permiso de uso.

## Bibliotecas y servicios
Se usan Node.js, Firebase Admin, Firebase Functions, bibliotecas de Android y dependencias transitivas, además de servicios de Firebase, Render y GitHub. Son herramientas de terceros, no desarrollos propios. Sus nombres y versiones están en package.json, package-lock.json y los archivos Gradle. Conservar los avisos de licencia de las dependencias al redistribuirlas; no se declara que todo el paquete tenga una única licencia propia.
La interfaz web actual usa HTML, CSS y JavaScript sencillo, sin un framework visual agregado. El ejercicio HTML básico y las colecciones Postman son recursos del proyecto asistido. Las evidencias señalan qué pruebas se ejecutaron y cuáles permanecen pendientes.
